Listas

Estrutura mutável que armazena elementos em sequência. Suporta operações de adição, remoção e indexação. 

# Exemplo de uso de listas
        frutas = ['maçã', 'banana', 'laranja']
        frutas.append('uva')       # adiciona ao final
        frutas.insert(1,'pera')    # insere na posição 1
        frutas.remove('banana')    # remove a primeira ocorrência
        print(frutas)              # saída: ['maçã', 'pera', 'laranja', 'uva']

List Comprehension

Sintaxe concisa para construir listas a partir de iteráveis, opcionalmente com condições. 

# Exemplo básico
        quadrados = [x**2 for x in range(6) if x % 2 == 0]
        print(quadrados)  # saída: [0, 4, 16]

Manipulação de Strings

Strings são imutáveis; use métodos embutidos para transformar e dividir textos. 

# Métodos úteis de string
        texto = "Olá, mundo"
        partes = texto.split(",")      # ['Olá', ' mundo']
        joined = "-".join(["a", "b", "c"])  # 'a-b-c'
        print(texto.replace('mundo', 'Python'))

Manipulação de Arquivos

Abra arquivos com o gerenciador de contexto with para garantir fechamento automático. 

# Leitura segura de arquivo
        with open('dados.txt', 'r', encoding='utf-8') as f:
            conteudo = f.read()
        print(conteudo)

Módulos e Pacotes

Organize código em módulos (.py) e pacotes (pastas com __init__.py). 

# importando módulo padrão
        import math
        print(math.sqrt(25))  # 5.0

        # importando função específica
        from datetime import datetime
        print(datetime.now())

Programação Orientada a Objetos (POO)

Classes, instâncias, construtores, herança e polimorfismo.

# Exemplo básico de classe
        class Pessoa:
            def __init__(self, nome, idade):
                self.nome = nome
                self.idade = idade

            def apresentar(self):
            return f"Olá, sou {self.nome} e tenho {self.idade} anos"

        p = Pessoa('João', 30)
        print(p.apresentar())

Exceções e Tratamento de Erros

Use try/except/finally para capturar e tratar erros previsíveis. 


        try:
            numero = int(input('Digite um número: '))
        except ValueError:
            print('Entrada inválida. Informe um número inteiro.')
        finally:
            print('Rotina finalizada')
