Comprehensions Avançadas

Listas, sets e dicionários podem ser criados de forma concisa usando comprehensions. 

# Lista de quadrados de números pares
        quadrados = [x**2 for x in range(10) if x % 2 == 0]
        print(quadrados)

        # Dicionário de números e seus quadrados
        quadrados_dict = {x: x**2 for x in range(5)}

        # Set de números únicos ao quadrado
        quadrados_set = {x**2 for x in range(5)}

Manipulação de Iteráveis

Funções como map, filter e zip permitem transformar, filtrar e combinar iteráveis. 


        numeros = [1, 2, 3, 4, 5]

        # map: aplica função a cada elemento
        dobrados = list(map(lambda x: x*2, numeros))

        # filter: filtra elementos pares
        pares = list(filter(lambda x: x % 2 == 0, numeros))

        # zip: combina iteráveis
        nomes = ['Ana', 'Bruno', 'Carlos']
        idades = [25, 30, 20]
        combinados = list(zip(nomes, idades))

Geradores e Iteradores

Produzem valores sob demanda, economizando memória em grandes coleções. 


        # Gerador simples
        def contador(max):
            n = 0
            while n max:
                yield n
                n += 1

        for i in contador(5):
            print(i)

Decoradores

Modificam o comportamento de funções ou métodos sem alterá-las diretamente. 


        def saudacao(func):
            def wrapper(*args, **kwargs):
                print('Olá!')
                return func(*args, **kwargs)
            return wrapper

        @saudacao
        def diga_nome(nome):
            print(f"Meu nome é {nome}")

        diga_nome('João')

Expressões Regulares

O módulo re permite buscar padrões em strings. 


        import re

        texto = 'Meu email é exemplo@gmail.com'
        padrao = r"\w+@\w+\.\w+"
        email = re.search(padrao, texto).group()
        print(email)
