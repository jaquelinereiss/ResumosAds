Estruturas e Algoritmos em Python

Tuplas (Sequenciais)

  • As tuplas em Python são coleções ordenadas e imutáveis
  • São declaradas com parênteses ( ) e podem armazenar tipos variados
  • Por serem sequenciais, suportam indexação, fatiamento e iteração 
        tupla = (10, "python", 3.14)
        print(tupla[1])
        #saída: "python"

Set (Conjuntos)

  • Um set é uma coleção não ordenada que não permite duplicatas
  • Útil para operações de conjuntos: união, interseção e diferença
  • Declarado com { } ou pela função set() 
        conjunto = { 10, "python", 3.14}
        print(conjunto)
        #saída: "python"

Dicionários em Python

  • Estrutura chave: valor, semelhante a mapas/tabelas de hash
  • Mutáveis: permitem inserir, alterar e remover pares
  • Ótimos para organizar e acessar dados rapidamente por chave 
        dicionario = { "nome": "Ana", "idade":25 }
        print(dicionario["nome"])
        #saída: Ana

Algoritmos de Ordenação

Técnicas para reorganizar elementos de uma lista em ordem crescente ou decrescente.

  • Bubble Sort: compara pares vizinhos e troca quando fora de ordem
  • Insertion Sort: insere cada elemento na posição correta de uma parte já ordenada
  • Merge Sort e Quick Sort: mais eficientes, baseados em divisão e conquista
  • Em Python, .sort() e sorted() usam o eficiente Timsort
