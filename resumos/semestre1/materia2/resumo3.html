Redes e Sub-redes

Segundo Kurose (2006), o Internet Protocol, ou simplesmente IP, é o endereço lógico feito para que um dispositivo possa se comunicar com qualquer outro dispositivo, independentemente de sua localização geográfica. O protocolo está definido na camada de rede, sendo o seu pacote denominado datagrama.

A notação de um endereço IP é separada por ponto, identificando uma parte como a rede (net), e a outra como o dispositivo (host). Veja os exemplos:

  • 172.16 - Identifica a qual rede o dispositivo pertence.
  • 30.110 - Identifica o endereço do dispositivo.

Além disso, a utilização do IP deve obdecer os seguintes critérios:

  • IP para Rede Privada: números de IP reservados para utilização dentro das LANs.
  • IP para Rede Pública: são faixas de números de IP utilizados para dispositivos acessíveis pela internet.

O roteador forma tabelas lógicas dos equipamentos disponíveis nas redes, como: roteador, switch, computadores, dispositivos móveis, impressoras IP e câmeras IP. Para auxiliar nesse processo é utilizado um mecanismo de descoberta de dispositivos “vizinhos”, que é efetuado por roteadores e switches por meio dos protocolos de comunicação:

  • Fast Ethernet:

    Definida como IEEE 802.3u, que permitiu que a velocidade de transmissão atingisse 100 megabits.

  • Ethernet Gigabit:

    Dez vezes superior à Fast Ethernet, essa versão permite velocidades de transmissão de até 1000 megabits.

  • Ethernet 10 Gigabit:

    Da mesma forma como ocorreu na versão anterior, esse padrão multiplicou a sua capacidade em 10 vezes, permitindo atingir uma velocidade de 10 Gigabit Ethernet, também conhecido como 10G.

Métodos de transmissão Ethernet

Tanenbaum (1997) define que as comunicações desse tipo de rede são efetuadas pelo protocolo Carrier Sense Multiple Access with Collision Detection (CSMA/CD), permitindo que qualquer dispositivo da rede possa efetuar uma transmissão sem hierarquizar quem tem prioridade.

Basicamente, para o funcionamento do protocolo, os dispositivos verificam se não há nenhuma comunicação ocorrendo para assim fazer uma transmissão.

Caso acorra de dois dispositivos emitirem, simultaneamente, uma mensagem um para o outro, uma colisão acontece e a transmissão é interrompida, sendo retomada em um tempo aleatório.

IPv6

O IPv6 surgiu como uma solução para a crescente escassez de endereços do IPv4, causada pelo aumento exponencial de dispositivos conectados à internet. Com o avanço da tecnologia e a popularização da internet móvel, dispositivos como smart TVs, smartphones, tablets, videogames, assistentes virtuais e dispositivos IoT (Internet das Coisas) passaram a demandar um número cada vez maior de endereços IP, tornando o IPv4 insuficiente para atender a essa necessidade.

Diferentemente do IPv4, que utiliza um espaço de 32 bits e pode suportar aproximadamente 4,3 bilhões de endereços, o IPv6 utiliza um espaço de 128 bits, possibilitando um número extremamente elevado de endereços. Essa expansão garante não apenas a conectividade contínua para os dispositivos atuais, mas também para futuras inovações tecnológicas.

Segundo Tanenbaum(1997), o novo protocolo deve:

  • - Resolver a escassez de endereços

  • - Simplificar o cabeçalho, facilitando o processamento dos pacotes e o aumento da velocidade do envio/recebimento

  • - Tornar os campos obrigatórios do cabeçalho como opcionais, facilitando o roteamento dos pacotes

  • - Garantir a segurança das transmissões, tornando o IPsec obrigatório
