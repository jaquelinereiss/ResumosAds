# 📝 Resumos ADS

Um website desenvolvido para centralizar e organizar resumos dos conteúdos estudados no curso de Análise e Desenvolvimento de Sistemas.
O projeto foi criado com fins de estudo, servindo como um repositório prático para aplicar conceitos de HTML, CSS e JavaScript puro, ao mesmo tempo em que auxilia na revisão dos temas da graduação.

## 📖 Objetivo do Projeto

- Praticar e reforçar conhecimentos em tecnologias web básicas
- Estruturar de forma organizada os resumos das disciplinas da graduação
- Criar uma experiência simples e funcional para navegação entre semestres e matérias
- Implementar modais dinâmicos para exibir resumos individuais
- Utilizar arquivos JSON como fonte de dados, consumidos dinamicamente pelo JavaScript

## ⚙️ Tecnologias Utilizadas

- HTML5 e CSS3
- JavaScript
- JSON (para armazenar os dados de matérias e resumos)

## 💡 Funcionalidades

- 📚 Organização dos resumos por semestres e matérias
- 📄 Exibição de resumos em modais dinâmicos via JavaScript
- 🎨 Estilização customizada e responsiva com CSS
- 🗂️ Estrutura baseada em JSON, permitindo fácil manutenção e adição de novos resumos
- 🔄 Separação entre dados (JSON) e lógica (JavaScript) para um código mais limpo e escalável
- 💻 Uso de query strings para identificar o semestre e a matéria selecionada via JavaScript.

## 📈 Possíveis melhorias futuras

- 🔠 Sistema de busca por palavra-chave nos resumos <br>
- 🔎 Filtro para buscar por  matéria e/ou disciplina <br>
